# System 8 — Event Marketing Operations

*Field marketing is a logistics business wearing a brand costume. The agent runs the logistics.*

## Event radar

A recurring scan finds relevant industry events (conferences, summits, trade weeks, partner activities) across the regions the team operates in, and writes qualified ones into a shared event calendar with structured fields: date, city, audience, relevance rationale, decision needed (attend / speak / sponsor / skip).

Two features that turned out to matter more than discovery itself:

- **Clash detection.** When multiple relevant events land in the same week across different cities, the radar surfaces the collision explicitly ("four cities, Sep 21–23 — who goes where?") instead of letting it be discovered in week-of panic.
- **Write/review separation.** Radar output that writes to shared calendars passes a reviewer check first — the same auditability pattern used for [published content](04-taste-gate.md).

## Deadline guards

Event deliverables have unforgiving deadlines (booth artwork due to printers, speaker forms, registration cutoffs). The agent runs *guard tasks* against each: deliver the artifact early, then at a set time on deadline day, check whether the stakeholder has responded — if yes, act on the feedback; if silent, send exactly one nudge with the fallback already attached ("deadline is today; the print-ready fallback version is in your DM; say the word or I submit the inquiry").

The discipline encoded: **a guard never re-produces work that's already delivered, and never nags twice.**

## Retrospectives that chase their own data

Every event gets a retrospective record from a standard template: costs, leads, pipeline touched, what worked, what to never do again. The failure mode of retrospectives everywhere is that nobody fills them in — so the agent chases: polite escalation to named owners on a schedule (day 3, day 8, day 19...), pre-filling every field it can from its own records first, so humans only supply what only they know.

Items that stay unfilled past the escalation ladder get surfaced as explicit close-or-kill decisions rather than rotting silently — "fill these 5 fields, or say 'archive' and I close it."

## Meeting prep (the field marketer's secret weapon)

When a meeting invite lands in the inbox, the agent automatically: creates the calendar event, researches external attendees (role, company, recent activity, likely agenda), and delivers a prep package before the meeting — context, attendee backgrounds, suggested focus points. Walking into every external meeting already briefed, at zero marginal effort, compounds fast in BD-heavy field marketing.
